# My Personal Website (GitHub Pages)

Welcome to the repository for my personal website, built using **HTML** and **CSS** and hosted via **GitHub Pages**. This is where I collect the pages, ideas, and projects that I enjoy working on.

## About This Project

This website serves as a space to experiment with web development and build a site from the ground up, step by step. The goal is to keep things organized and fun, while making room for topics that interest me—such as aviation and small coding or web-related experiments.

## File Structure

Currently, the project consists of the following files:

* `index.html` — The main page of the website, featuring navigation, a welcome section (`header`), highlighted topics (`main`), and a footer (`footer`).
* `style.css` — The styling and layout for the page (colors, fonts, buttons, cards, etc.), linked via `<link rel="stylesheet" href="style.css" />`.
* `README.md` — This project description, explaining the setup and usage of the repository.

*(Additional pages, such as `projects.html` and `planes.html`, will be added over time.)*

## Viewing the Site Live via GitHub Pages

1. Ensure that `index.html` and `style.css` are located in the root directory of the repository.
2. In GitHub, navigate to **Settings** > **Pages**.
3. Verify that the branch is set to `main` and the directory is set to `/ (root)`.
4. Once GitHub Pages is active, the live URL for the website will appear.
